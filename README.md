# Nallıhan Koltuk Yıkama — statik landing page

## GitHub Pages'e yayınlama
1. ZIP dosyasını açın ve içindeki dosyaları GitHub deposunun **kök dizinine** yükleyin.
2. GitHub deposunda **Settings → Pages** bölümünü açın.
3. **Build and deployment** altında `Deploy from a branch` seçin.
4. Branch olarak `main`, klasör olarak `/(root)` seçip **Save**'e basın.
5. Birkaç dakika sonra GitHub Pages adresiniz hazır olur.

## Özelleştirme
- Telefon numarası ve WhatsApp bağlantıları `index.html` içinde `0541 785 06 46` ve `905417850646` olarak geçiyor.
- Renkler `style.css` dosyasının başındaki `:root` değişkenlerinden ayarlanabilir.
- Logo: `assets/logo-transparent.png` (dairesel logonun dışı şeffaf PNG).
- Sayfa statiktir; sunucu, veritabanı veya build adımı gerektirmez.

## Not
Google Fonts kullanımı için internet bağlantısı gerekir; yazı tipleri yüklenemezse sistem fontlarına düşer.
